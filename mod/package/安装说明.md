# 安装说明

> 《妹控计划》读屏无障碍补丁 · 发布包内文档

## 这是什么

这是《妹控计划》的**读屏无障碍补丁**，让使用屏幕阅读器的玩家也能游玩本作。

- **不是官方补丁**，与可味玩 KawayiPlay 没有任何关系，未获授权
- **仅限正版玩家**：请先通过 Steam 购买本作（AppID 4169160）
- 补丁**不修改任何游戏文件** —— 由 BepInEx 在运行时挂载，卸载就是删文件
- 本补丁**不含任何游戏资源、剧本原文或反编译产物**
- 补丁代码与文档采用 **MIT 许可**发布，附加的署名要求与免责条款见仓库根目录的
  LICENSE 与 NOTICE.md；随包第三方组件的许可证见包内 `licenses\THIRD-PARTY-NOTICES.txt`

## 装之前

- Windows 10 / 11（64 位）
- 游戏已安装，能正常启动
- 一个可用的读屏后端：**NVDA**（推荐，走 NVDA Controller Client）、
  **争渡读屏（ZDSR）**（本机要装有争渡，且是**商业版 / 青春版** —— 公益档没有 API 权限，
  会被如实判为不可用；补丁会读注册表**自动找到争渡的安装目录**，
  不需要你往游戏目录放任何文件，发布包里另外带了一份**可删的兜底 dll**）、
  **Tolk 支持的其他读屏**（JAWS、SuperNova 等）、或系统自带的 **SAPI** 语音

> ⚠ **游戏不能装在含中文的路径下。**
> 这不是本补丁的怪癖：BepInEx + HarmonyX 在非 ASCII 路径下打补丁会抛
> `IL Compile Error … Illegal byte sequence`，而且**部分补丁已经生效**，
> 症状是「有些功能莫名其妙不工作」。Steam 默认装在
> `F:\Steam\steamapps\common\妹控计划` —— 这个路径本身没问题（游戏目录名不影响），
> 但如果你的库路径里有中文，建议换一个纯英文的库。

## 安装（分步）

1. 关闭游戏。
2. 到 Releases 下载 `MeiKongA11y-<版本>.zip`，解压。
3. 把解压出来的东西**整体**拷进游戏根目录 —— 也就是有 `MeiKongProject.exe` 的那一层。
4. 提示「是否合并 / 替换」时选**是**。
5. 启动游戏。听到「妹控计划无障碍补丁已加载……」，就说明通了。

### 三条容易踩的坑

- `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 必须在**游戏根目录**
- `BepInEx\core\` 里的文件**一个都不能少**
- `nvdaControllerClient.dll` 放游戏根目录（Mono 查找 DLL 时**先看应用目录**）

### 已经装过别的 BepInEx 模组？

只需要两个文件：

- `MeiKongA11y.dll` → `BepInEx\plugins\`
- `nvdaControllerClient.dll` → 游戏根目录

**不要**覆盖对方已有的 `winhttp.dll` 和 `BepInEx\core\`。

## 卸载

删掉游戏目录下的 `winhttp.dll` 即完全失效；连同 `BepInEx\` 一并删掉就彻底干净。
存档不受影响。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| **`F1`** | **功能菜单** —— 念出六个功能入口并编号，按数字直达（小游戏 / 番茄钟 / 日程表 / 设置 / 故事与收藏 / 换装） |
| **`F2`** | **状态播报** —— 当前显示模式、诗萌在屏幕哪个方位、当前面板、可操作项数量、番茄钟剩余时间 |
| **`F3`** | **戳一下诗萌** —— 等价于用鼠标左键点她本人 |
| **`F4`** | **和诗萌聊聊** —— 按下当前可见的「和诗萌聊聊」按钮 |
| **`F5`** | **切回全屏（保命键）** —— 任何时候按都能从桌宠模式切回全屏 |
| **`F9`** | **切换语音后端** —— 按一下切到下一个**当前可用**的后端（循环顺序 `自动 → Tolk → NVDA → 争渡 → SAPI`），当前不可用的会被跳过并在播报里说明；选择会写进配置文件，下次启动仍生效。留空配置项即停用 |
| **`Esc`** | 在小游戏窗口里**按两次**关掉它（第一次只是举起来并提示，按其它任意键取消） |
| `1`-`9` | 选择对应编号的选项 |
| `Backspace` | 重读最近收到的那句台词 |
| `Tab` | 进入 / 退出界面导航模式 |
| `↑` `↓` | 上一项 / 下一项 |
| `←` `→` | 调整滑条；**在记忆翻牌里是在 4×4 牌阵上移动光标** |
| `回车` / `空格` | 导航模式下激活控件；**记忆翻牌里是翻开当前这张牌** |
| `Home` / `End` | 第一项 / 最后一项 |
| `PageUp` / `PageDown` | 切换面板组（换组时会念出「第几组 / 共几组」） |

**游戏原生占用的键**：空格 / 回车 / 小键盘回车 / 鼠标滚轮 = 推进剧情，
按住 `Ctrl` = 快进，`R` = 历史记录。

> **`F1` 是游戏自己的开发者测试键**，不是补丁加的 —— 按一下会从**开局第一句重播、
> 打断当前剧情**。补丁默认把它屏蔽掉（配置：`交互` → `屏蔽游戏原生的 F1 测试键`），
> 所以 F1 只当功能菜单用。
>
> 另外：全屏界面与小游戏窗口，游戏本身**不认 Esc**（正常人是用鼠标点窗口的关闭按钮）。
> 补丁在小游戏里把 Esc 变成了那个按钮 —— 要按两次，防止误触。

> **`F9` 和中文 Windows 的输入法**：`Alt+Shift` 是 Windows 默认的**输入法 / 输入语言切换键**，
> 所以「和游戏抢键」时最顺手的 `Alt+Shift+F9` 用起来也可能别扭。
> 「切换语音后端按键」接受任何「修饰键+主键」写法（`F9`、`Alt+Shift+F9`、`Ctrl+Alt+F9`…），
> 但**修饰键必须完全对上** —— 配置写 `F9` 时，按住 Alt 再按 F9 **不会**触发
> （这是刻意的：免得抢走游戏自己的 `Alt+F9`）。
> 纯数字键名会被拒绝，要数字键请写 `Alpha0`。

### 记忆翻牌怎么玩

打开小游戏面板后，补丁会自动接管方向键：

- `↑` `↓` `←` `→` 在 **4×4 牌阵**上移动，位置按**牌的真实屏幕位置**算，念「第 X 行第 Y 列，背面」；
- `回车` 翻开当前这张；
- 翻开的结果会**立刻**念出来（「你翻开第 1 行第 2 列：金色舞台」）；
- 诗萌翻的牌也会念（「诗萌翻开第 3 行第 2 列：抱猫」）—— 正常人这时候也在看着；
- 配对成败会说（「配对成功，浴巾」/「没配上，两张都盖回去了」）。

> **刻意不做的事**：已经盖回去的牌是什么，补丁**不记**。
> 那正是这个游戏唯一考的东西 —— 正常人靠脑子记，盲人也得靠自己记。
> 补丁只报「此刻屏幕上看得见的」。

## 配置

配置在 `BepInEx\config\meikong.a11y.reader.cfg`，也可以装
[ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager) 在游戏里改。

配置分四组：

- **朗读** —— 朗读无配音剧情 / 有配音的行也自动朗读 / 朗读选项 / 数字键选择选项 / 重读按键 / 切换语音后端按键 / 语音后端
- **界面导航** —— 菜单键盘导航 / 按屏幕位置排序控件 / 只导航看得见的控件 /
  退出前二次确认 / 退出确认对象名 / 排除的对象名
- **交互** —— 功能菜单键 / 状态播报键 / 面板开关时自动播报 / 戳一下诗萌 / 和诗萌聊聊 / 切回全屏（保命键）
- **其它** —— 播报等配音放完 / 启动时播报 / 界面诊断日志

> **「语音后端」怎么选**：可填 `自动` / `Tolk` / `NVDA` / `争渡` / `SAPI`。
> `自动` 按 **Tolk → NVDA → 争渡 → SAPI** 挑第一个可用的；钉死某一个且它不可用时
> **不会回退** —— 这是刻意的，专门用来排查「为什么不出声」。
> 运行中按 `F9`（配置项：`切换语音后端按键`）可以切到下一个**当前可用**的后端，
> 不可用的会被跳过并在播报里说明，选择会写进配置文件。

> **争渡读屏（ZDSR）这一档不需要你做任何事**：补丁会先读 Windows「卸载」登记项里的
> `InstallLocation`（`DisplayName` 含「争渡」或 `zdsr` 的那些，HKLM 两个视图 + HKCU），
> 自动找到争渡的安装目录 —— **装在别的盘、装到自定义目录也算数**；
> 找不到再试 `%ProgramFiles(x86)%\zdsr\zdsr` 这类默认位置。
> 搜索顺序是 **注册表登记的安装目录 → 默认安装目录 → 插件目录（包内那份）
> → 游戏目录**，安装目录里那份**永远优先**（它会跟着读屏一起升级）。
>
> 发布包的 `BepInEx\plugins\` 里**另外带了 `ZDSRAPI_x64.dll` 与 `ZDSRAPI.dll`
> 两份兜底**（32 / 64 位各一，运行时按进程位数自动选），给那些在自己机器上
> 翻不到这个 dll 的人。带的是**打包机**上的版本，可能比你本机的争渡旧；
> **旧了也不要紧** —— 补丁发现它报「版本不匹配」时会**自动换下一份候选**，
> 不会卡住你。**删掉这两个文件即可回到「只读安装目录」**，功能不变。
> 想知道当前用的是哪一份，看日志那一行的 `DLL=` 路径。
>
> 这两个文件是**争渡读屏**的产物（不是我们的，也不受本补丁的 MIT 许可覆盖）：
> 未经修改、原样随这个免费非商业补丁再分发，署名与依据见包内
> `licenses\THIRD-PARTY-NOTICES.txt`。本包**不带 `ZDSRAPI.ini`**。
>
> 排查用的环境变量 `A11Y_ZDSR_DIR` 可以钉死搜索目录（多个用 `;` 分隔）；
> 一旦设置就只找它列出的目录。日常用不到。

> **为什么默认不朗读有配音的行**：全作 1392 行台词里 **1353 行（97.2%）有配音**。
> 配音本身就是内容，读屏叠上去两边都听不清。需要确认文字时按 `Backspace` 重读。
> 想吃「全语音 + 全文本」的玩家，把配置里「有配音的行也自动朗读」打开即可。
