## 主要快捷键

| 快捷键 | 功能 |
|---|---|
| `1`-`9` | 选择对应编号的选项 |
| `0` | 限时选择里「立刻沉默」 |
| `Backspace` | 重读最近朗读过的一段 |
| `Tab` | 进入 / 退出界面导航模式 |
| `↑` `↓` | 上一项 / 下一项 |
| `←` `→` | 调整滑条 |
| `回车` / `空格` | 导航模式下激活控件；否则交给游戏推进剧情 |
| `Home` / `End` | 第一项 / 最后一项 |
| `PageUp` / `PageDown` | 切换面板组 |
